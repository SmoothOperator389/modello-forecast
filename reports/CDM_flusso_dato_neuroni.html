1 · Dato grezzo → riga di feature (as_of)

Prima della rete non ci sono neuroni: solo aggregazioni causali fino ad as_of (ieri incluso).

Una previsione = una riga PDV × SKU × as_of. Lo storico dopo as_of non entra mai nelle feature (no leakage).

2 · Struttura layer e neuroni (shape del tensore)

Ogni cerchio ≈ unità/neurone del Dense. Le Embedding espandono un ID in un vettore denso.

Concat embedding = 81 dim (6+8+12+4+4+6+4+6+4+4+4+4+3 + mq4+mq4+weather4) + numeriche 57 = vettore 138. Poi Dense 256 → 256 → 128 → 64 → 1.
Step Operazione Neuroni / dim Cosa cambia nel dato
grezzo scontrini, anagrafiche, meteo… — eventi grezzi nel tempo
feat aggregazioni fino ad as_of ~80 colonne 1 riga PDV×SKU×as_of
L0 Embedding + BN numeric 81 + 57 ID → vettori; numeri normalizzati
L1 Concatenate 138 un unico vettore di attivazioni
L2–L4 3 residual Dense 256 → 256 → 128 feature non lineari + skip connection
L5a Head SKU 64 → 1+1 scala e delta rispetto al prior
out ReLU(prior×scale + delta) 1 pezzi previsti ≥ 0

3 · Esempio numerico (didattico)

Numeri inventati ma coerenti con le formule del codice — per vedere come il valore si trasforma.

SKU “giacca blu” nel PDV di Milano · as_of = 18/09 · RR_14d = 0.8 pezzi/giorno → prior = 0.8 × 15 = 12.
PassoInputTrasformazioneRisultato
Grezzo 11 pezzi venduti negli ultimi 14 giorni in quel PDV 11 / 14 ≈ 0.79 → run_rate_14d RR ≈ 0.8
Prior RR_14d = 0.8 × orizzonte 15 sku_prior = 12
Encoder sku_id = "020H3…", pdv = "MI01", colore = "BLU" map string→int (UNK=0 se nuovo) es. sku=1842, pdv=37, colore=9
Embedding sku=1842 lookup riga 1842 nella matrice Emb (vocab × 12) vettore 12 float (es. [0.2, −0.1, …])
Numeric RR, temp=18°, sconto=0, … (57 valori) (x − μ_train) / σ_train + BatchNorm vettore 57 ≈ N(0,1)
Concat 81 emb + 57 num Concatenate vettore 138
Tronco 138 Residual 256→256→128 (ReLU, skip) vettore x ∈ ℝ¹²⁸
Head x (128) Dense 64 → scale Softplus, delta lineare es. scale=1.15 · delta=+1.2
Output prior=12, scale=1.15, delta=+1.2 ReLU(12 × 1.15 + 1.2) = ReLU(15.0) y_sku = 15.0 pezzi / 15 gg
Lettura La rete non “indovina da zero”: parte da 12 (ritmo recente), alza del 15% (meteo/profilo SKU) e aggiunge +1.2 pezzi (promo/contesto). All’init: scale≈1, delta=0 → uguale al naive.
