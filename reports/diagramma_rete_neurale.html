Dual-head TensorFlow — struttura della rete

Fedele a testing/model/dual_head_tf.py · ~380k parametri

Come leggerlo: dall’alto verso il basso. Entrano chi/cosa + numeri + prior → tronco residuale 256→256→128 → due uscite (SKU operativa a sinistra, categoria a destra). La linea tratteggiata del prior salta il tronco e arriva alla moltiplicazione.

BN = Batch Normalization · Drop = Dropout · softplus = sempre ≥ 0 · ReLU = pezzi ≥ 0

Formula SKU: previsione = ReLU( prior × scale + delta )
